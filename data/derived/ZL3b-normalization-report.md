## Policy (read before trusting any downstream statistic)

- Alternative reading `[x:y]` -> **first option `x` kept**, both logged below. IVTFF 2.0 specifies that the first option is the transcriber's most likely reading, so this is the intended default rather than a neutral coin flip. `alternative_reading_sensitivity.py` generates a deliberately adverse last-option corpus to test whether downstream results depend on that editorial preference.
- `,` (uncertain word space) -> treated as a word boundary, same as `.`, but counted separately so analyses can exclude these loci if word-boundary certainty matters.
- `<->` (drawing intrusion) -> treated as a word boundary (text on either side was not contiguous in the source manuscript).
- `?` (illegible character) -> left in place as a literal `?` in the token, not stripped or replaced. This means a word containing `?` will not match its otherwise-identical counterpart elsewhere in frequency counts -- flag for the Statistician before running word-frequency stats.
- Inline markup (`<%>`, `<!@NNN;>`, `<$>`, extended-Eva `@NNN;` escape codes, etc.) -> stripped entirely; these are editorial/rendering annotations, not glyphs.
- Ligature/grouped glyphs (`{...}`) -> left intact as part of the token, not split into components.
