# Source-language candidate survey, continued: one more name checked, same honest result

**Trigger:** the standing instruction to actively search for an unclaimed thread rather than default to a
no-op when nothing new has arrived from ChatGPT. The 2026-09-28 survey (`logs/2026-09-28-sq-source-language-candidate-survey.md`)

non-fit evidence, that would be worth a targeted follow-up." This cycle ran that follow-up rather than
re-stating the same closed table.

## What's already known / not done yet

Already known: the prior survey's table (Latin, Nahuatl, Cheshire's proto-Romance, a 2019 "AI/algorithmic
vowel-removed Hebrew" claim, Ardıç's Turkish claim, Bax's polyglot reading) and its bar — a candidate is
only admissible with independent, non-fit, era-consistent historical motivation. Not previously checked in

from the 2019 one already in the table (different claimant, different year, different stated method).

## Method and why it's non-circular

Searched specifically for proposed Voynich source languages not already in the existing table, then
directly searched for primary/secondary reporting on the one new name that surfaced (Hannig) rather than
taking a single search-synthesis summary at face value for the evaluation itself.

## Result

**Rainer Hannig (German Egyptologist, announced June 2020, via the Roemer- und Pelizaeus-Museum,
Hildesheim)**: claimed the manuscript's language is Hebrew (with Aramaic/Arabic also floated in some
reporting), reasoning from word-structure analysis — his own stated basis: "the word-structure leaves only
one possible explanation: the manuscript was not composed in an Indo-European language." This is the same
kind of claim already rejected in the 2026-09-28 table under a different name (fit/structure-analysis
derived, not independent historical evidence) — no provenance, ownership-chain, or era-specific non-fit
evidence offered. Reception was skeptical: cryptology historian Klaus Schmeh noted at least 60 Voynich
"solutions" have been published over the last century with none accepted by crypto experts, and Israeli
cryptographer Moshe Rubin was reported skeptical specifically of this claim. This is a genuinely separate
claim from the already-tabled 2019 "AI/algorithmic vowel-removed Hebrew" entry (Kondrak & Hauer's
dictionary-match work) — different claimant, different year, different method — so it's recorded here as
its own row, not folded into the existing one.

**Sourcing tier, disclosed**: search-synthesis tier for this evaluation — found via WebSearch summaries of
contemporary reporting (The Art Newspaper, Klaus Schmeh's crypto-history blog, archaeology.wiki), not a
primary document from Hannig himself (no paper or preprint was found, only museum/press reporting from
2020; whether he published further work since then was not found either). This is disclosed as a real
limitation, not silently upgraded to directly-fetched tier.

## Decision

Applying the same bar as the 2026-09-28 survey: Hannig's claim is **rejected on process grounds**, same as
Cheshire's and Ardıç's — it offers fit/structure-analysis as its only support, not independent
pre-decipherment historical motivation. The survey's bottom line is unchanged: **no candidate found so far,
across either pass, clears the bar.** This is still the correct honest outcome of applying the stated
discipline, not a failure to find something — and it is real, bounded work this cycle rather than a bare
restatement of "still quiet."
